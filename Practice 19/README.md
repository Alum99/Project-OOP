Реестр недвижимости

Простое консольное приложение для управления объектами недвижимости на Python с использованием принципов ООП.

Функциональность

- Создание объектов недвижимости и риэлторов  
- Просмотр всех объектов фирмы  
- Просмотр конкретного объекта или риэлтора  
- Агрегация риэлторов в объектах недвижимости  

Структура программы

- Realtor — класс, описывающий риэлтора (ФИО и стаж работы).  
- Property — класс, описывающий объект недвижимости (адрес, тип, цена, список риэлторов).  
- RealEstateCompany — класс фирмы, содержащий список всех объектов недвижимости.  
- RealEstateRegistry — основной класс программы (контроллер), реализующий логику меню и взаимодействие с пользователем.
