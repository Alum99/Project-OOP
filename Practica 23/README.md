Пример реализации паттерна Компоновщик (Composite) на Python для управления солдатами в строю.
Существует строевой устав, который определяет, как управлять строем и согласно этому уставу абсолютно не важно кому отдается приказ (например «шагом марш») одному солдату или целому взводу. Соответственно в устав (если его в чистом виде считать паттерном «компоновщик») нельзя включить команду, которую может исполнить только один солдат, но не может исполнить группа, или наоборот.
